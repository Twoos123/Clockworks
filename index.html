Spiral Knights

A single-player port that plays from your own game install. The game's files stay on your computer: nothing is uploaded or downloaded.

Choose the game's install folder (the one containing rsrc). For a Steam install that is usually C:\Program Files (x86)\Steam\steamapps\common\Spiral Knights.

You can also drop the folder onto this page.
