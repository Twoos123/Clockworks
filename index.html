Clyde Web Viewer

A browser viewer for models built with Three Rings' open-source Clyde engine. It reads models straight from your own game install. Files stay on your computer and are never uploaded.

Pick the game's install folder (the one containing rsrc). For a Steam install that is usually C:\Program Files (x86)\Steam\steamapps\common\Spiral Knights.

You can also drop the folder onto this page.
